# 同人圈經營模擬器 v4.0

一款模擬同人誌販售的經營策略遊戲。以台灣同人場為背景，體驗同人創作者從選題、創作、出版到販售的完整流程。目標是累積 $1,915,000（一張台積電）！

## 遊戲特色

### 核心玩法
- **觀察市場** — 瀏覽三大社群平台（Feetbook、Y、2ch），觀察作品人氣趨勢與粉絲討論
- **研究與創作** — 研究作品提升理解度、研究市場掌握受眾數據、創作草稿累積作品
- **出版決策** — 選擇封面品質、紙質等級、印量與定價，每項選擇影響成本與銷量
- **場次販售** — 模擬同人展販售，8 種顧客類型各有不同購買傾向
- **經營管理** — 升級社團能力、管理庫存、控制成本、招募社員

### 社團升級系統（15 種）
- 培訓小幫手（銷售上限）、僱傭 Coser（攤位吸引力）、文筆提升、印量擴充
- 社群經營（銷量倍率）、親友團（保底銷量）、市場分析達人、聖德太子
- 天使投資人（借款額度）、Adobe 全家桶（品質加成）、社團空間（成員上限）等

### 社團成員系統
- **30 名社團成員**（15R / 10SR / 5SSR），各有獨特效果與個性
- **慶功宴抽卡** — 場次結算後舉辦慶功宴招募成員，費用遞增
- 場次等級影響稀有度機率（小型同人展 SSR 3% → Comic Market SSR 15%）
- 12 種效果類型：銷量倍率、吸引力、品質、保底銷量、印刷減免、倉儲減免等
- 重複抽卡退還 50% 費用，滿員時可替換現有成員

### 高級場次系統
- **小型同人展** — 入場免費，標準難度（第 1 回合起）
- **大型同人展** — 入場費 $10,000，來場 1.25 倍，品質敏感度提升（第 6 回合解鎖）
- **Comic Market** — 入場費 $100,000，來場 3 倍，高品質高報酬/低品質高風險（第 12 回合解鎖）

### 存檔槽位系統
- 5 個獨立存檔位，支援多路線策略
- 舊版存檔自動遷移至槽位 1
- 存檔選擇畫面顯示社團名、回合數、資金、時間戳

### 成就系統（58 項）
- 涵蓋新手、財務、創作、升級、社群、場次、社團成員等 17 個分類
- 隱藏成就與特殊獎勵（起始資金加成、成本減免、行動點加成等）
- 階梯式獎勵：累計解鎖成就可增加新遊戲起始資金（最高 +$12,000）

### 社群平台觀察
- **Feetbook** — 粉絲向社群，正面偏好高
- **Y（前身是推特）** — 即時資訊平台，病毒傳播力強
- **2ch** — 匿名討論板，毒舌與爭議多
- 社群事件隨機觸發，影響作品人氣與銷量

### 收藏品市場
- 買賣 ACG 相關收藏品，價格隨市場事件波動
- 低買高賣賺取差價，作為額外收入來源

### 其他機制
- **8 種顧客類型** — 路人、潛水黨、迷因人、愛好者、收藏家、課金黨、評論家、黑粉
- **作品人氣衰退** — 不同題材衰退速度不同，當季新番快、經典慢
- **隨機事件** — 場次中觸發各種事件影響銷量
- **開發者日誌** — 點擊版本文字 5 次開啟，可查看詳細計算過程

## 快速開始

1. 下載或 clone 此專案
2. 用瀏覽器開啟 `doujin-sim.html`
3. 選擇存檔槽位，開始新遊戲
4. 輸入社團名稱，開始經營！

## 專案結構

```
flyingFaucet/
├── doujin-sim.html        # 主遊戲檔案（HTML + 遊戲邏輯）
├── balance-config.js      # 遊戲平衡參數（升級、場次、成員、顧客等）
├── content-templates.js   # 內容模板（社群貼文、事件、成員台詞）
├── js/
│   ├── achievement-system.js  # 成就系統（58 項成就 + 階梯獎勵）
│   ├── platform-engine.js     # 社群平台引擎（貼文生成 + 社群事件）
│   ├── upgrade-system.js      # 社團升級模組（15 種升級）
│   ├── event-system.js        # 隨機事件模組
│   ├── sales-calculator.js    # 銷量計算與預估模組
│   ├── inventory-manager.js   # 庫存管理模組
│   ├── dev-logger.js          # 開發者日誌模組
│   └── game-over.js           # 遊戲結束模組
└── README.md
```

## 技術資訊

- **技術棧**: 純 HTML5 + CSS3 + JavaScript（無框架）
- **無需建置**: 直接開啟 HTML 即可遊玩
- **瀏覽器支援**: Chrome、Firefox、Edge、Safari（最新版本）
- **儲存**: 使用 localStorage（5 個獨立存檔槽位）
- **RNG**: Seeded PRNG（Mulberry32），確保同種子可重現

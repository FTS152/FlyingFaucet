# 同人場模擬器 (Doujin Convention Simulator)

一款模擬同人誌販售的經營模擬遊戲。以台灣同人場為背景，體驗同人創作者從選題、創作到販售的完整流程。

## 🎮 遊戲特色

### V2 主要功能

#### 社團升級系統
- **小幫手**: 增加單場最大銷售量
- **倉儲升級**: 降低庫存倉儲成本
- **天使投資人**: 增加借款額度與緊急週轉金

#### 隨機事件系統
- 場次中會遇到各種隨機事件
- 事件會影響銷量、收入、來客數等
- 包含官方動態、社群熱潮、天氣因素等多種事件類型

#### 銷售上限機制
- 單場銷售有人力上限限制
- 升級小幫手可提高上限
- 錯失銷售機會會有提示

#### 庫存管理
- 未售出的庫存會有倉儲成本
- 長期庫存會累積費用
- 可選擇退休作品減少成本

#### 遊戲結束條件
- 資金歸零且無借款額度 = 破產結束
- 堅持 20 回合 = 生存成功

#### 開發者日誌
- 隱藏功能：點擊版本文字 5 次開啟
- 記錄銷售計算、事件觸發等詳細過程
- 可匯出日誌供除錯使用

#### 詳細結算報告
- 顯示每件作品的銷量、收入
- 標示事件對銷售的影響
- 支援按收入/銷量/名稱排序

#### 銷量預估系統
- 根據市場研究等級提供銷量預估
- 研究越深入，預估越準確
- 結算時比較預估與實際差異

#### 作品衰退度
- 不同題材有不同的人氣衰退速度
- 當季新番衰退快，經典作品衰退慢
- 庫存明細顯示衰退趨勢

#### 顧客類型差異化
- 封面和紙質對不同顧客有不同吸引力
- 收藏家重視紙質，迷因人重視封面
- 粉絲組成顯示各類型偏好

#### 封面與紙質選項
- 4 種封面等級：免費自製 / 基礎 / 精緻 / 頂級
- 4 種紙質等級：經濟 / 標準 / 優質 / 豪華
- 不同選擇影響成本與吸引力

## 🚀 快速開始

1. 下載或 clone 此專案
2. 用瀏覽器開啟 `doujin-sim.html`
3. 點擊「開始新遊戲」
4. 享受遊戲！

## 📁 專案結構

```

├── doujin-sim.html      # 主遊戲檔案

├── js/
│   ├── dev-logger.js      # 開發者日誌模組
│   ├── upgrade-system.js  # 社團升級模組
│   ├── event-system.js    # 隨機事件模組
│   ├── sales-calculator.js # 銷量計算模組
│   ├── inventory-manager.js # 庫存管理模組
│   └── game-over.js       # 遊戲結束模組
└── specs/               # 開發規格文件
```

## 🎯 遊戲流程

1. **觀察階段** - 觀察市場趨勢，選擇題材
2. **創作階段** - 研究作品、研究市場、創作草稿
3. **準備階段** - 出版作品、設定價格、選擇材質
4. **販售階段** - 進行場次販售
5. **結算階段** - 查看銷售結果、管理社團升級
